In our case, since we are making 2D point clouds, we can have the third coordinate of means3D to be 0. The reason we don't just change it to 2D is because the model uses PyTorch3D, and this is easier than trying to replace that.

After massive simplifications made to the repo, the model now only predicts displacement of points, and calculates loss through position error (before, it calculated loss based on rendering error too). Rendering should be completely disabled

Because of this, we literally only need means3D, which tracks the position of each point in a point cloud. The rest can be replaced with placeholders. According to Codex, these placeholders should work:

N = means3D.shape[1]
log_scales = np.zeros((1, N, 3), dtype=np.float32)
logit_opacities = np.zeros((1, N, 1), dtype=np.float32)
shs = np.zeros((1, N, 16, 3), dtype=np.float32)
unnorm_rotations = np.zeros((1, N, 4), dtype=np.float32)
unnorm_rotations[..., 0] = 1.0  # identity quaternion: [1, 0, 0, 0]
